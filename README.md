# Tweaks

## Commands

```sh
/rename "name" #Renames the held item using the Minimessage syntaxe
```
> **Permissions**
> - tweaks.rename
> - tweaks.*


___
```sh
/fly #Toggles player fly
```
> **Permissions**
> - tweaks.fly
> - tweaks.*

___
```sh
/flyspeed 1 #Sets the fly speed from x1 to x10
```
> **Permissions**
> - tweaks.flyspeed
> - tweaks.*

___
```sh
/lock #Locks the held item preventing it from being dropped or transferred outside the player's inventory
```
> **Permissions**
> - tweaks.lock
> - tweaks.*

___
```sh
/unlock #Unlocks the held item
```
> **Permissions**
> - tweaks.unlock
> - tweaks.*
