# Tweaks

## Commands

```sh
/rename "name" #Renames the held item using the Minimessage syntaxe
```
> **Permissions**
> - tweaks.rename
> - tweaks.*


___
```sh
/fly #Toggles player fly
```
> **Permissions**
> - tweaks.fly
> - tweaks.*

___
```sh
/flyspeed 1 #Sets the fly speed from x1 to x10
```
> **Permissions**
> - tweaks.flyspeed
> - tweaks.*
